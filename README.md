# Tech Labs

Interactive labs that show how AI systems work, step by step, in the browser.

| Lab | What it is | Live |
|-----|------------|------|
| [RAG Lab](rag-lab/README.md) | Build a small Retrieval-Augmented Generation system from a fictional company's documents and watch every step: chunking, vectors, cosine search, the prompt and the answer. Polish by default, English available. | https://rag-lab.warsztaty-ai.com/ |

Each lab lives in its own folder with its own README. RAG Lab is published at the site root.
